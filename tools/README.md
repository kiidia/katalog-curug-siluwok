# Alat pengelolaan konten

`data/species.json` adalah salinan data terstruktur yang digunakan saat paket ini dibuat. Situs di dalam ZIP sudah berupa HTML statis dan tidak memerlukan build.

Untuk pembaruan kecil, edit langsung halaman HTML atau ganti gambar di `assets/images/species/`. Jika nanti ingin mengubah situs menjadi generator otomatis, gunakan JSON tersebut sebagai sumber konten.
